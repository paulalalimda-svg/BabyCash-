# Contributing to BabyCash

Gracias por contribuir. Este documento contiene reglas rápidas para ramas y commits.

- Ramas:
  - feat/<short-desc>  — nuevas funcionalidades
  - fix/<short-desc>   — correcciones de bugs
  - chore/<short-desc> — tareas internas y mantenimiento
  - docs/<short-desc>  — documentación

- Commits: usa Conventional Commits breves y claros:
  - feat(auth): use SecureRandom for reset codes
  - fix(mail): read mail credentials from env in prod
  - chore(ci): add linting

- Pull Requests:
  - Un PR = una intención clara. Mantén los cambios pequeños y con pruebas si aplica.

- Reescribir autor:
  - No reescribas historia pública a menos que entiendas el impacto. Para reescribir localmente usa `git filter-repo` o `git filter-branch` con precaución.

Gracias por ayudar a mejorar BabyCash.
